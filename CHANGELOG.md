# Changelog

Изменения группируются по категориям: добавлено, изменено, удалено.

## 0.1.0 — 2026-10-05

### Добавлено

- API создания и получения заказов на FastAPI с in-memory хранилищем.
- Асинхронная имитация обработки с задержкой 0,05–0,5 секунды.
- Пять метрик Prometheus и эндпоинт `/metrics`.
- Валидация суммы, идентификаторов и валюты; обработка дубликатов.
- Очистка Gauge и резервирования идентификатора при ошибках и отмене запроса.
- Тесты API, метрик и конкурентного поведения.
- Настройки строгого mypy и Ruff, Dockerfile, инструкции запуска.

### Изменено

- Нет: первоначальная версия проекта.

### Удалено

- Нет: первоначальная версия проекта.
